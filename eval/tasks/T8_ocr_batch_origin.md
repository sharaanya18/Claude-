# Task T8 — Recovering OCR batch origin from character noise (paraphrased from the user's own challenge notes)

Each test "bag" contains 16-50 text snippets (OCR output from historical newspapers/documents) that came from 2-4 different OCR processing batches. Partition each bag's snippets into groups (one batch label per snippet). Submission: `bag_id, batch_id` where batch_id is a whitespace-separated list of labels, one per snippet ordered by the integer after `::` in the snippet id.
Metric: mean over bags of max(0, adjusted_rand_score(truth, prediction)). Degenerate answers (all-one-group, all-singletons) score 0.
Data: train.csv has snippets from 19 batches (rows ordered by batch); test has 110 bags, 3,687 snippets drawn from 16 batches that never appear in train. Reference numbers in the prompt: shipped reference solution 0.342; word TF-IDF 0.079; char n-gram TF-IDF 0.038; length-only 0.089; closed-set classifier assigning each snippet to the most likely TRAIN batch 0.210; a (banned) global-pooling shortcut 0.094; AI baseline to beat 0.40; leaderboard high 0.44.
Rules: use only the data directory; CPU only (10 cores, 62 GB, 1.5 h); no network; no pretrained weights; do not match test rows back to any source archive; partition each bag ON ITS OWN, only that bag's rows may be used for its partition; no pooling or clustering of the whole test set; do not lean on snippet length or language identity.
