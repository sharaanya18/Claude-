# U13 — Warehouse object detection with selective human review (user-supplied, verbatim)

## Overview
Build an object detector that helps a warehouse auditor locate inventory and equipment. For each photograph, return object boxes and optionally choose one small rectangular region for human review. The auditor completes the inventory inside that region; your detector remains responsible for the rest of the photograph.
Each example is one RGB warehouse photograph. Five object types: small load carrier (0), forklift (1), pallet (2), stillage (3), pallet truck (4). Objects can be stacked, partially occluded, very small or blurred. Detect individual annotated instances, including individually distinguishable pallets in stacks. A stillage is a rigid storage frame or cage; a small load carrier is a small reusable container. Follow the bounding-box conventions demonstrated in the training examples. The annotation catalog can omit ambiguous or barely visible objects.
The review window may cover at most 10% of the image area. Review is simulated as correct completion of every reference object whose entire bounding box lies inside the window. Objects only partly intersecting it still need automatic detection. No human response is supplied.
Training and test warehouses are disjoint. Several photographs can depict the same physical objects, and the warehouse group is the appropriate unit for validation. Complete solution within 90 minutes (installation, permitted weight downloads, preprocessing, training, validation, inference, submission writing); one NVIDIA A10G 24 GB VRAM, 62 GB RAM. General-purpose COCO or ImageNet pretrained weights permitted, along with training on the supplied training images and domain-valid augmentation.

## Dataset
dataset/public/: train.csv, test.csv, sample_submission.csv, images/im_<opaque>.jpg. Coordinates normalized to image width/height, origin upper left; continuous box convention without adding one pixel.
train.csv: id, image, group_id (opaque warehouse identifier for grouped validation), width, height, detections (JSON array of [class_id, xmin, ymin, xmax, ymax]), review ([] in training because the complete reference inventory needs no human assistance). test.csv: id,image,group_id,width,height. Test warehouse IDs do not appear in training. sample_submission.csv: id,detections,review - predicts no objects, requests no review.

## Submission
working/submission.csv with id,detections,review. detections: JSON array of [class_id, xmin, ymin, xmax, ymax]; class ids integers 0-4; 0<=xmin<xmax<=1, 0<=ymin<ymax<=1; [] for none. No confidence values. Repeated detections are separate predictions and can incur false-positive cost. review: [] or one [xmin, ymin, xmax, ymax] with same rules and (xmax-xmin)*(ymax-ymin) <= 0.10; boundary-touching box counts as fully contained. Rows and detections in any order. Example: demo_a,"[[2,0.10,0.20,0.40,0.50]]","[0.70,0.05,0.95,0.45]" ; demo_b,[],"[0.80,0.00,1.00,0.50]".

## Evaluation (0 to 1, larger better)
For each photograph, remove submitted boxes fully contained in the review window and replace them with the fully contained reference boxes (simulated human removes false detections and supplies missed objects entirely within the region). No review when review is []. Match remaining submitted boxes to remaining reference boxes separately for each class; eligible when IoU >= 0.75; one-to-one maximum matching. For each warehouse and class, pool counts over its images: true_positives = automatic_matches + fully_reviewed_reference_objects; predicted_objects = remaining_submitted_objects + fully_reviewed_reference_objects; reference_objects = all_reference_objects; class_f1 = 2*TP/(predicted + reference). Average class_f1 over classes with at least one prediction or reference object in that warehouse, then average warehouse scores equally. A class absent from both sides is omitted; an entirely empty warehouse cohort scores 1. False detections in an otherwise absent class receive zero class credit and enter the warehouse average. Complete correct boxes with no review score 1; no detections and no review score 0 on images containing reference objects.

## Not allowed
Additional training images or annotations beyond the supplied set; pretrained weights trained specifically on industrial or warehouse datasets; looking up the source collection or recovering external annotations; manual annotation or human inspection of test images to choose predictions or review windows; external inference APIs or remote model execution; fitting or adapting model parameters, thresholds or review policies on test images; combining information across different test images during inference; using IDs, filenames, row order or serialization artifacts to infer targets.
