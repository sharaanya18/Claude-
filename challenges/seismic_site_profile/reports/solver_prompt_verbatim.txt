PHASE 4 — REPRODUCE THE EXACT EVALUATION METRIC

Implement the challenge metric locally exactly.

The metric is:

1. macro-F1 independently for each depth cell
2. average over four cells
3. convert to skill relative to the blind policy

Formula:

"cell_score = mean(macro_F1_cell1, macro_F1_cell2, macro_F1_cell3, macro_F1_cell4)"

"blind = mean(1 / K_cell)"

where "K_cell" is the number of bands present in that cell.

Then:

"score = (cell_score - blind) / (1 - blind)"

and clamp:

"max(0.001, min(1.0, score))"

Implement this as the single primary evaluation metric.

Do NOT optimize ordinary accuracy.

Do NOT optimize micro-F1 as the main target.

Do NOT judge a model solely by loss.

Because this is macro-F1:

- rare classes matter heavily
- class collapse is dangerous
- always predicting the majority class is useless
- probability quality alone is not sufficient
- decision boundaries matter strongly

Create:

"metric.py"

and independently test it on known/artificial examples.
