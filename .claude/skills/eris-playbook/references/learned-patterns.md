**L001 Information ceiling by Monte Carlo (matching / correspondence tasks)** — When: one-to-one matching of items whose cross-view signal is weak and spread over many dimensions (AnchorPerm) · What: measure canonical correlations of true pairs on train, simulate jointly-Gaussian pairs with those correlations, run the ML matcher (Hungarian on the CCA-weighted bilinear score) per hidden-set size, and compare with the model's accuracy; a model within ~5% of that ceiling cannot be improved by capacity, only by new information · Gain: avoided a week of tweaks (clean accuracy 0.56 vs ceiling ~0.57-0.59) · Cost/Risk: assumes a linear-Gaussian generator; nonlinear extras make the true ceiling slightly higher · Evidence: anchorperm, own measurement [1x].

**L002 Simulated-shift proxies can track the platform** — When: the description says held-out representation regimes exist but no train regime label does · What: match unlabeled summary statistics of the evaluation inputs to simulated shifts (letter frequencies -> additive code noise sigma ~0.7; covariance spectrum -> NOT noise, partly changed cross-role map) and report CV per simulated shift next to clean CV · Gain: the simulated-noise and partial-rotation CV (0.585 / 0.572) predicted the platform score (0.58) within 0.01 · Cost/Risk: only a rank-ordering proxy; do not tune to one public number · Evidence: anchorperm [1x].

**L003 Row-local models cannot learn a changed cross-view mapping** — When: train covers one familiar mapping and the evaluation regime changes the role mappings (AnchorPerm transfer rows) · What: tower/bilinear scorers collapse to chance under rotated, sign-flipped or permuted coordinates; rotation/partial-rotation augmentation, QAP structure terms, two-pass pseudo-anchors, Sinkhorn decode, richer heads and context encoders all gave 0 to -0.02 accuracy · Gain: none (negative result worth keeping) · Cost/Risk: the only large lever left is pooling unlabeled/anchor information across evaluation rows, which CLAUDE.md 2.3.5 bans (test-time adaptation) · Evidence: anchorperm, public score 0.5934 / 0.58 vs baseline 0.5616 [1x].
