# /eris-resume <slug>

Read `CLAUDE.md`, `challenges/<slug>/CHALLENGE_NOTES.md`, the experiment log and the latest reports. Report exactly three sentences: (1) last experiment and last CV/LB, (2) the planned next experiment, (3) any compliance
or runtime risk to flag. Then proceed with the next experiment (via `/eris-experiment`) unless the user redirects. Do not stop after the summary.
